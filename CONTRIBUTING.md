# Contributing

Thanks for your interest in voxel-world. This guide covers the basics of
building, verifying, and committing changes to this project.

## Build

```bash
make build        # Release build (default)
make run          # Build and run
make run-debug    # Debug build with RUST_BACKTRACE=1
```

The Makefile sets `DYLD_LIBRARY_PATH` and `VK_ICD_FILENAMES` for macOS MoltenVK,
so build and run through `make` rather than invoking the binary directly.

Requires Rust 1.94.1+ and the Vulkan SDK.

## Verify before committing

Run the full quality gate before every commit. Do not commit if any step fails:

```bash
make checkall     # Format + clippy + tests (run after every change)
```

This is the project's definition of "done" — `make checkall` must pass cleanly.

## Commit discipline

Commit after every logical batch of work, not at the end of a long session. This
keeps diffs reviewable and makes rollback trivial.

1. Run `make checkall`.
2. Fix every error and warning.
3. Commit immediately with a descriptive conventional-style message
   (e.g. `fix(net): …`, `feat(editor): …`, `docs: …`).

## Code conventions

These match the rest of the codebase; follow them in new code.

- **Logging:** use the `log` crate macros (`log::debug!`, `log::info!`,
  `log::warn!`, `log::error!`). Do not use `println!` / `eprintln!` in
  production code paths — they are restricted to `#[cfg(test)]` blocks.
  Component prefixes like `[Server]`, `[Client]`, `[World Gen]` stay inside the
  format string; severity is carried by the macro choice.
- **No panics in production:** avoid `.unwrap()` / `.expect()` outside of
  `#[cfg(test)]`. Return a `Result` or handle the error explicitly. The Vulkan
  init paths in `gpu_resources.rs` / `vulkan_context.rs` are the known exception
  — a GPU failure there means the game cannot continue.
- **Rust ↔ GLSL constants** are auto-generated by `build.rs` into
  `shaders/generated_constants.glsl`. Edit the Rust source of truth
  (`src/chunk.rs`, `src/constants.rs`, `src/render_mode.rs`, `src/svt.rs`) — do
  not hand-edit the GLSL constants.

## Reporting issues

Open a GitHub issue at <https://github.com/paulrobello/voxel-world/issues> with
the reproduction steps, your platform, and the `make run-debug` output if a
crash is involved. See [SECURITY.md](SECURITY.md) for vulnerability reporting
instead of a public issue.
